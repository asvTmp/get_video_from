# Video Downloader (`get_video.ps1`)

PowerShell-скрипт для одиночного и пакетного скачивания потокового видео (`.m3u8`) в формат `.mp4` с помощью `yt-dlp` и `ffmpeg`.

## Структура проекта

Для корректной работы разместите файлы в следующей структуре:

```text
project_folder/
├── get_video.ps1        # Основной скрипт
├── videos.json          # Список ссылок для пакетного скачивания (опционально)
├── bin/                 # Исполняемые файлы и библиотеки
│   ├── yt-dlp.exe
│   ├── ffmpeg.exe
│   ├── ffprobe.exe
│   └── *.dll
└── result/              # Папка для готовых видео (создается автоматически)
```

> **Важно:** Все `.exe` и `.dll` файлы должны находиться строго в подпапке `bin` рядом со скриптом.

---

## Параметры запуска

| Короткий ключ | Полный ключ | Обязательный | По умолчанию | Описание |
| :--- | :--- | :---: | :--- | :--- |
| `-n` | `-Name` | Для одиночного режима | — | Имя выходного файла (без расширения `.mp4`). |
| `-u` | `-Url` | Для одиночного режима | — | Прямая ссылка на `.m3u8` плейлист. |
| `-f` | `-File` | Для пакетного режима | — | Путь к JSON-файлу со списком видео. |
| `-d` | `-dir_dst` | Нет | `.\result` | Папка для сохранения видео (создается сама, если её нет). |
| `-h`, `-?` | `-Help` | Нет | — | Вывод встроенной справки и примера JSON. |

---

## Как работать со скриптом

### 1. Просмотр справки
Запустите скрипт без параметров или с флагом `-h`:
```powershell
.\get_video.ps1
```

### 2. Скачивание одного видео
Укажите имя файла (`-n`) и ссылку (`-u`). Файл сохранится в папку `.\result`:
```powershell
.\get_video.ps1 -n "Лекция 1 - Введение" -u "https://.../playlist.m3u8"
```

С сохранением в указанную папку (`-dir_dst`):
```powershell
.\get_video.ps1 -n "Лекция 1" -u "https://.../playlist.m3u8" -dir_dst "D:\Videos\Course"
```

### 3. Пакетное скачивание из JSON-файла
Создайте файл `videos.json` в кодировке **UTF-8** со следующей структурой:

```json
[
  {
    "name": "Lecture 1 - Introduction",
    "url": "https://.../playlist.m3u8"
  },
  {
    "name": "Lecture 2 - Logic",
    "url": "https://.../playlist.m3u8"
  }
]
```

Запустите пакетную загрузку:
```powershell
.\get_video.ps1 -f "videos.json"
```

С сохранением всей подборки в отдельную подпапку:
```powershell
.\get_video.ps1 -f "videos.json" -dir_dst "module_01"
```

---

## Особенности работы

- **Пропуск дубликатов:** если в целевой папке уже есть непустой `.mp4` файл с таким же именем, скрипт пропустит его (`[Skipped]`) и перейдет к следующему.
- **Автоочистка имен:** запрещенные в Windows символы (`\ / : * ? " < > |`) в названии автоматически заменяются на `_`.
- **Докачка при обрыве:** если загрузка прервалась, при повторном запуске `yt-dlp` продолжит скачивание с места остановки.
- **Ограничение режимов:** нельзя одновременно использовать `-f` и параметры `-n` / `-u`.

# Disk Speed Test (`test_ssd.ps1`)

Утилита на PowerShell для тестирования реальной скорости последовательной записи и чтения накопителей в Windows **без прав администратора**.

## Особенности работы

* **Обход кэша оперативной памяти:** при чтении используется Win32 API (`CreateFile` с флагом `FILE_FLAG_NO_BUFFERING`), что исключает искажение результатов за счёт системного кэша Windows.
* **Три раздельных этапа:** генерация случайных данных в ОЗУ, запись на диск и чтение выполняются по очереди с отдельными таймерами и прогресс-барами.
* **Несжимаемые данные:** для теста записи генерируются криптостойкие случайные байты, чтобы контроллер SSD не завышал скорость за счёт сжатия нулей.

## Требования и первый запуск

* Windows 10 / 11 и PowerShell 5.1 или выше.
* Права администратора **не требуются**.
* Если система блокирует запуск `.ps1`-файлов, разрешите выполнение скриптов для текущего окна консоли:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## Синтаксис

```powershell
# Полный тест (генерация -> запись -> некэшированное чтение)
.\test_ssd.ps1 <DriveOrDir> [-s | --size <MB>] [-k | --keep] [-l | --log <LogPath>]

# Тест только чтения на существующем файле
.\test_ssd.ps1 -f | --file <PathToExistingFile> [-l | --log <LogPath>]
```

*(Запуск скрипта без аргументов выводит встроенную справку).*

## Параметры

| Параметр | Обязательный | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| `<DriveOrDir>` | Да (если не задан `-f`) | — | Буква диска (`D:`, `D`) или путь к папке (`D:\Test`). Для диска `C:` файл создаётся в папке профиля пользователя (`$env:USERPROFILE`). |
| `-s`, `--size <MB>` | Нет | `1024` | Размер генерируемого тестового файла в мегабайтах. |
| `-f`, `--file <Path>` | Нет | — | Путь к существующему файлу для проверки только скорости некэшированного чтения (этапы генерации и записи пропускаются). |
| `-k`, `--keep` | Нет | Отключено | Не удалять сгенерированный временный файл (`speedtest_<size>mb.tmp`) после завершения теста. |
| `-l`, `--log <Path>` | Нет | — | Путь к `.csv`-файлу для сохранения истории замеров (разделитель `;`). |
| `-h`, `--help`, `/?` | Нет | — | Вывод справки по использованию. |

## Примеры использования

**1. Базовый тест диска `D:` файлом 1 ГБ (по умолчанию):**
```powershell
.\test_ssd.ps1 d:
```

**2. Тест диска `D:` файлом 4 ГБ с сохранением файла на диске после проверки:**
```powershell
.\test_ssd.ps1 d: --size 4096 --keep
```

**3. Тест скорости чтения на уже существующем файле (образе или видео):**
```powershell
.\test_ssd.ps1 -f "D:\speedtest_4096mb.tmp"
```

**4. Запуск с записью результатов в CSV-таблицу:**
```powershell
.\test_ssd.ps1 d: -s 2048 --log C:\tmp\benchmark_results.csv
```

## Ограничения

* В режиме автогенерации весь тестовый объём сначала создаётся в оперативной памяти, поэтому размер `-s` не должен превышать объём свободной ОЗУ на ПК.
